# Ornament provenance

Everything in this directory is generated by `pnpm ornaments`
(scripts/generate-ornaments.mjs) and owned outright. Nothing here is traced
from or derived from the reference images, which are stock illustrations.

| File | What it is |
|---|---|
| lantern-a.png | Round red lantern, eight ribs, long tassel |
| lantern-b.png | Slightly narrower lantern, seven ribs, shorter tassel |

Regenerate rather than edit: the seeds are fixed, so the script reproduces
these files exactly.
