# Texture provenance

Everything in this directory is generated by `pnpm textures`
(scripts/generate-textures.mjs) from seeded noise and owned outright. Nothing
is photographed, traced or licensed. The seeds are fixed, so the script
reproduces these files exactly; regenerate rather than edit.

| File | What it is |
|---|---|
| paper-red.webp | Seamless 1200px tile of crumpled red paper |
| paper-cream.webp | Seamless 1200px tile of lightly creased cream paper |
| print-speckle.webp | 384px tile mask that wears display type like old print |
| chili-slice-a/b/c.webp | Painted slices of fresh chilli, transparent |
